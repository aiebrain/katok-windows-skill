# katok-windows

Codex에서 실행 중인 **Windows 카카오톡 화면을 조회하고, 사용자 지시에 따라 개별 텍스트를 입력·전송하는 스킬**입니다.

- 스킬명: `katok-windows`
- 호출: `$katok-windows`
- 스킬 파일: [skills/katok-windows/SKILL.md](skills/katok-windows/SKILL.md)

이 저장소에는 작업 지침만 들어 있습니다. 실제 앱 조작은 Codex의 Windows Computer Use가 수행합니다. `katok.exe`나 독립 실행 봇을 설치하는 저장소가 아닙니다.

## 필요한 환경

- Windows와 공식 카카오톡 PC 앱
- 사용자가 로그인한 카카오톡 세션
- Codex에서 사용 가능한 `computer-use:computer-use` 스킬
- 해당 스킬이 지원하는 `node_repl` 및 `@oai/sky` Windows 앱 제어 경로

Computer Use 런타임은 이 저장소에 포함하지 않습니다. Codex 환경에 따라 해당 기능이 없을 수 있습니다. 이 스킬을 복사하는 것만으로 Windows 앱 제어 기능이나 권한이 추가되지는 않습니다. 로그인·보안·개인정보 권한은 사용자가 직접 처리합니다.

## 설치

이 저장소는 비공개입니다. 소유자 또는 접근 권한이 있는 GitHub 계정으로 인증된 환경에서 설치해야 합니다. 스킬 파일을 설치해도 다른 사람에게 저장소 접근 권한이 생기지 않습니다.

Codex에서 다음과 같이 요청합니다.

```text
$skill-installer https://github.com/aiebrain/katok-windows-skill/tree/main/skills/katok-windows 스킬을 전역 설치해줘.
```

직접 설치하려면 이 저장소를 내려받아 `skills/katok-windows` 폴더를 사용자 Codex 스킬 디렉터리로 복사합니다. 기본 경로는 `~/.codex/skills/katok-windows`입니다. `CODEX_HOME`을 별도로 지정했다면 해당 위치의 `skills` 디렉터리를 사용합니다. 기존 동명 스킬이 있으면 먼저 내용을 비교하고 백업하세요.

다음 요청에서 스킬 목록에 `katok-windows`가 표시되는지 확인합니다. 다른 환경에서 자동으로 동작한다고 가정하지 말고 Computer Use의 실제 앱 열거·창 읽기부터 확인하세요.

## 사용 예

```text
$katok-windows 카카오톡에서 '예시 대화방' 화면을 확인해줘.
```

```text
$katok-windows '예시 대화방'에 '안녕하세요'를 입력만 하고 보내지는 마.
```

```text
$katok-windows '예시 대화방'에 '안녕하세요'라고 지금 한 번 보내줘.
```

대상이 모호하면 먼저 방을 확인합니다. 전송은 적용되는 Computer Use 정책에 따라 정확한 대상·최종 문구·실행 시점 승인을 확인한 뒤 수행합니다. 설치나 개선 요청을 테스트 메시지 전송 승인으로 사용하지 않습니다.

## 동작 흐름

1. 열린 카카오톡 창에서 대상 방을 찾습니다.
2. 현재 화면으로 방, 입력창, 기존 작성 내용과 포커스를 확인합니다.
3. 요청한 문구를 입력하고 새 화면에서 확인합니다.
4. 유효한 전송 승인이 있으면 한 번 전송합니다.
5. 전송 전 상태와 비교해 새 발신 말풍선과 빈 입력창을 확인합니다.

입력 도구가 오류를 내더라도 이미 문구가 입력됐을 수 있습니다. 먼저 화면을 다시 읽고, 정확한 전체 문구가 있다면 재입력하지 않습니다. 전송 결과가 불명확하면 자동 재전송하지 않습니다. 세부 내용은 [UI 작업 절차](skills/katok-windows/references/ui-workflow.md)에 있습니다.

## 기능과 검증 범위

| 항목 | 상태 |
|---|---|
| 실행 중인 앱·창 선택과 화면 읽기 | Windows 실제 환경에서 확인 |
| 사용자 지정 단일 텍스트 입력·한 번 전송·새 말풍선 확인 | 실제 요청 1건에서 확인 |
| 오류 후 중복 입력·전송 방지 절차 | 실제 입력 오류 경험과 가상 시나리오 8건으로 검토 |
| UI 대화방·메시지 검색 | 작업 절차 제공, 검색 흐름 전체는 별도 실사용 검증 필요 |
| 여러 줄·이미지·파일 전송 | 검증 범위 밖 |
| 전체 대화 DB 추출, BM25·의미 검색, 백그라운드 동기화 | 제공하지 않음 |
| 예약·반복·대량 발송 | 제공하지 않음 |

검증일은 2026-09-09입니다. 당시 입력 관련 호출에서 발생한 `window is not a usable app window` 오류의 내부 원인은 확인되지 않았습니다. 이 스킬의 복구 절차가 해당 런타임 오류 자체를 수정한 것은 아닙니다. 앱 업데이트·화면 구성·권한 차이에 따라 동작을 다시 확인해야 합니다.

## 데이터와 권한

- 카카오톡 로컬 DB, 암호화 키, 인증 캐시를 읽지 않습니다.
- 앱의 화면과 접근성 정보는 작업 중 Codex/Computer Use에 전달될 수 있습니다. 완전한 오프라인 처리를 보장하는 도구가 아닙니다.
- 대화 본문·수신자·스크린샷을 별도 파일이나 로그에 기본 저장하지 않습니다. 보고서나 Obsidian 기록도 일반 단건 전송마다 만들지 않습니다.
- 대화방을 열면 읽음 상태가 바뀔 수 있으며, 읽음 상태 보존을 보장하지 않습니다.
- 전송 후 말풍선 확인을 상대방의 수신·읽음 확인으로 확대 해석하지 않습니다.
