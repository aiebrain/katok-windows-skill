# katok-windows

Codex에서 실행 중인 **Windows 카카오톡 화면을 조회하고, 사용자 지시에 따라 개별 텍스트를 입력·전송하는 스킬**입니다.

- 스킬명: `katok-windows`
- 호출: `$katok-windows`
- 스킬 파일: [skills/katok-windows/SKILL.md](skills/katok-windows/SKILL.md)

이 저장소에는 작업 지침이 들어 있습니다. 실제 앱 조작은 Codex의 **Windows Computer Use**가 수행합니다. 스킬을 설치한 뒤 아래 요청 예시를 Codex에 붙여 넣어 사용합니다.

> **처음이라면:** 설치 → 카카오톡 창 읽기 확인 → 초안 입력 → 확인한 초안 한 번 전송 순서로 진행하세요. 이 저장소만 설치해도 모든 Codex 환경에서 PC 제어가 가능해지는 것은 아닙니다.

문서 기준일: 2026-09-10 · 실제 Windows 전송 검증일: 2026-09-09

## 할 수 있는 일

- 실행 중인 카카오톡과 지정한 대화방의 화면 확인
- 현재 화면에서 읽은 대화 요약
- 카카오톡 UI를 이용한 대화방·메시지 검색 절차
- 지정한 텍스트를 입력창에 초안으로 작성
- 정확한 방과 최종 문구에 대한 사용자 지시를 확인한 뒤 개별 텍스트 한 번 전송

현재 보이는 화면을 다루는 스킬입니다. 모든 과거 대화를 자동 수집하거나 검색하는 도구는 아니며, 세부 검증 범위는 아래 표를 참고하세요.

## 필요한 환경

- Windows와 공식 카카오톡 PC 앱
- 사용자가 로그인한 카카오톡 세션
- Codex에서 사용 가능한 `computer-use:computer-use` 스킬
- 해당 스킬이 지원하는 `node_repl` 및 `@oai/sky` Windows 앱 제어 경로

Computer Use 런타임은 이 저장소에 포함하지 않습니다. Codex 환경에 따라 해당 기능이 없을 수 있습니다. 이 스킬을 복사하는 것만으로 Windows 앱 제어 기능이나 권한이 추가되지는 않습니다. 로그인·보안·개인정보 권한은 사용자가 직접 처리합니다.

## 설치

이 저장소는 공개되어 있어 누구나 문서를 읽고 내려받을 수 있습니다. 저장소를 읽거나 설치 파일을 받기 위한 별도 접근 승인은 필요하지 않습니다. 카카오톡 로그인과 Computer Use 사용 준비는 별도로 확인해야 합니다.

Codex에서 다음과 같이 요청합니다.

```text
$skill-installer https://github.com/aiebrain/katok-windows-skill/tree/main/skills/katok-windows 스킬을 전역 설치해줘.
이미 같은 이름의 스킬이 있으면 먼저 비교하고 백업해줘.
설치 결과와 이 환경에서 스킬을 인식시키는 다음 단계를 알려줘.
카카오톡 메시지는 보내지 마.
```

설치 도구가 안내한 새 작업 또는 재시작 절차를 따르고, 스킬 목록에서 `katok-windows`가 인식되는지 확인하세요.

수동 설치가 필요하면 저장소의 `skills/katok-windows` 폴더 전체를 사용자 Codex 스킬 폴더로 복사합니다. Windows 기본 위치는 `%USERPROFILE%\.codex\skills\katok-windows`입니다. `CODEX_HOME`을 별도로 지정했다면 해당 위치의 `skills` 폴더를 사용합니다. `SKILL.md`와 `references/ui-workflow.md`를 함께 보존하고, 기존 동명 스킬은 비교·백업한 뒤 처리하세요.

## 설치 후 준비 확인

카카오톡 PC 앱을 실행하고 직접 로그인한 뒤 Codex에 요청합니다.

```text
$katok-windows 스킬이 인식되는지와 Windows Computer Use를 사용할 수 있는지 확인해줘.
실행 중인 카카오톡 메인 창을 읽을 수 있는지만 확인해줘.
대화방을 열거나 메시지를 입력·전송하지 마.
사용할 수 없는 기능이 있으면 필요한 준비를 알려줘.
```

**스킬 설치 성공**과 **실제 카카오톡 창 읽기 성공**은 별개입니다. 기능이 없거나 창을 읽을 수 없다면 메시지 작업을 시작하지 마세요. 로그인·잠금·권한 동의가 필요하면 본인이 직접 처리합니다.

## 처음 사용하기: 화면 확인 → 초안 → 전송

아래 `연습방`은 가상의 이름입니다. 본인이 사용할 정확한 대화방 이름으로 바꾸세요. 먼저 직접 관리하는 연습용 방에서 짧은 한 줄로 시작하면 확인하기 쉽습니다.

### 1. 대화방 확인

```text
$katok-windows 카카오톡의 '연습방' 화면을 확인해줘.
같은 이름의 방이 여러 개면 먼저 나에게 확인해줘.
메시지는 입력하거나 보내지 마.
```

확인된 방이 내가 의도한 방인지 살펴봅니다. 대화방을 열면 읽음 상태가 바뀔 수 있습니다.

### 2. 초안 입력

```text
$katok-windows '연습방' 입력창에 '안녕하세요. 테스트 메시지입니다.'를 입력만 해줘.
기존 작성 내용이 있으면 덮어쓰지 말고 멈춰줘.
전송 버튼이나 Enter는 누르지 마.
```

입력창의 **전체 문구**를 확인하세요. `초안 입력 확인`은 메시지를 보냈다는 뜻이 아닙니다.

### 3. 확인한 초안 한 번 전송

2단계에서 입력이 확인됐고 아직 전송을 시도하지 않았을 때만 요청합니다.

```text
$katok-windows 지금 '연습방'에 입력된 초안이 '안녕하세요. 테스트 메시지입니다.'와 정확히 같은지 확인해줘.
정확히 같으면 다시 입력하지 말고 이 초안만 지금 한 번 보내줘.
방이나 내용이 다르거나 이미 전송을 시도했을 가능성이 있으면 멈춰줘.
전송 후 새 발신 말풍선과 빈 입력창을 확인해줘.
```

전송 지시에는 **정확한 방·최종 문구·지금 한 번 보낸다는 행동**을 명시합니다. 적용되는 Computer Use 정책에 따라 유효한 실행 승인이 확인되면 수행합니다. 같은 실행에 대한 승인을 반복해서 묻지는 않지만, 대상이나 내용이 달라지면 변경된 부분을 확인해야 합니다. 설치나 개선 요청 자체는 테스트 메시지 전송 승인이 아닙니다.

## 추가 요청 예시

아래는 각각 독립적인 요청입니다. 위 연습을 마친 뒤 같은 메시지를 다시 보내는 순서가 아닙니다.

### 현재 보이는 대화 요약

```text
$katok-windows '연습방'에서 현재 보이는 대화만 짧게 요약해줘.
읽은 범위를 알려주고 화면에 없는 내용은 추정하지 마.
별도 파일 저장이나 메시지 전송은 하지 마.
```

### 방 안에서 단어 검색

```text
$katok-windows '연습방' 안에서 '회의'라는 단어를 UI 검색으로 찾아줘.
실제로 확인한 결과와 읽은 범위만 알려줘. 메시지는 보내지 마.
```

대화방 찾기와 방 안의 메시지 검색은 서로 다릅니다. 화면에 결과가 없다는 이유만으로 전체 대화에도 해당 내용이 없다고 단정하지 않습니다. 검색 흐름 전체는 별도 실사용 검증이 필요합니다.

### 새 메시지 한 번 전송

아직 해당 메시지의 입력·전송을 시작하지 않은 경우에 사용합니다.

```text
$katok-windows '연습방'에 '내일 오전 10시에 뵙겠습니다.'라고 지금 한 번 보내줘.
기존 초안이 있거나 대상 방이 모호하면 멈추고 알려줘.
전송 후 새 발신 말풍선과 빈 입력창으로 확인해줘.
```

## 결과 확인

| 보고 | 의미 |
|---|---|
| 화면 조회 확인 | 요청한 화면을 읽음 |
| 초안 입력 확인 | 입력창에 전체 문구가 있음. 전송 완료 아님 |
| 전송 확인 | 전송 직전 상태 이후 정확한 새 발신 말풍선이 생겼고 입력창도 비어 있음 |
| 전송 여부 미확인 | 성공 여부를 판단할 증거가 부족함. 자동 재전송하지 않음 |

예전의 같은 문구, 빈 입력창, 도구 호출 성공 중 하나만으로 전송 완료를 판단하지 않습니다. 전송 확인도 상대방의 읽음 확인을 뜻하지 않습니다.

## 동작 흐름

1. 열린 카카오톡 창에서 대상 방을 찾습니다.
2. 현재 화면으로 방, 입력창, 기존 작성 내용과 포커스를 확인합니다.
3. 요청한 문구를 입력하고 새 화면에서 확인합니다.
4. 유효한 전송 승인이 있으면 한 번 전송합니다.
5. 전송 전 상태와 비교해 새 발신 말풍선과 빈 입력창을 확인합니다.

입력 도구가 오류를 내더라도 이미 문구가 입력됐을 수 있습니다. 먼저 화면을 다시 읽고, 정확한 전체 문구가 있다면 재입력하지 않습니다. 전송 결과가 불명확하면 자동 재전송하지 않습니다. 세부 내용은 [UI 작업 절차](skills/katok-windows/references/ui-workflow.md)에 있습니다.

## 오류가 났을 때

오류 직후에는 “다시 보내” 대신 아래처럼 요청하세요.

```text
추가 입력·삭제·전송은 하지 말고 같은 대화방 화면을 다시 읽어줘.
현재 입력창과 직전 상태 이후 새 발신 말풍선을 확인해줘.
보낸 여부가 불분명하면 '전송 여부 미확인'으로 알려주고 멈춰줘.
```

| 관찰된 상태 | 처리 |
|---|---|
| 입력 오류 후 같은 방에 정확한 전체 초안이 있음 | 재입력하지 않음. 아직 전송 시도가 없을 때만 원래 요청의 다음 단계 판단 |
| 입력 오류 후 입력창이 비었거나 일부만 입력됨 | 자동 재입력하지 않고 멈춤 |
| 입력창에 다른 글이 있거나 방이 다름 | 삭제·덮어쓰기 없이 멈추고 대상·내용 확인 |
| 전송 후 새 발신 말풍선과 빈 입력창 확인 | 전송 확인, 다시 보내지 않음 |
| 전송 후 내용이 남거나 새 말풍선인지 구분 불가 | 전송 여부 미확인, 자동 재전송하지 않음 |
| 창을 읽지 못하거나 로그인·잠금·권한 화면이 나타남 | 조작 중단. 필요한 사용자 조치 후 화면부터 확인 |

**전송을 시도했을 가능성이 있으면 입력 복구 단계로 되돌아가 다시 보내지 않습니다.** 오류 반환은 입력이나 전송이 실행되지 않았다는 증거가 아닙니다.

## 자주 묻는 질문

**스킬을 설치했는데 PC를 조작하지 못해요.**

Windows Computer Use 실행 환경이 있는지 확인하세요. 이 저장소는 작업 지침을 제공하며 런타임이나 PC 제어 권한을 설치하지 않습니다.

**설치 후 스킬 목록에 나타나지 않아요.**

설치 위치와 폴더 구조를 확인하고 설치 도구가 안내한 새 작업·재시작 절차를 따르세요. 이전 검증에서는 다음 요청에서 발견했지만 모든 환경의 동작을 보장하지는 않습니다.

**같은 이름의 대화방이 여러 개예요.**

화면에 보이는 참여자와 맥락을 대조하고, 여전히 모호하면 직접 대상을 지정하세요. 제목만 보고 임의로 보내지 않습니다.

**사진이나 파일, 예약 메시지도 되나요?**

여러 줄·사진·파일 전송은 현재 검증 범위 밖입니다. 예약·반복·대량 발송은 제공하지 않습니다.

**GitHub 접근 권한을 따로 받아야 하나요?**

공개 저장소이므로 문서를 읽고 내려받기 위한 별도 승인은 필요하지 않습니다. 자신의 카카오톡 로그인과 Codex 사용 환경은 따로 준비해야 합니다.

## 기능과 검증 범위

| 항목 | 상태 |
|---|---|
| 실행 중인 앱·창 선택과 화면 읽기 | Windows 실제 환경에서 확인 |
| 사용자 지정 단일 텍스트 입력·한 번 전송·새 말풍선 확인 | 실제 요청 1건에서 확인 |
| 오류 후 중복 입력·전송 방지 절차 | 실제 입력 오류 경험과 가상 시나리오 8건으로 검토 |
| UI 대화방·메시지 검색 | 작업 절차 제공, 검색 흐름 전체는 별도 실사용 검증 필요 |
| 여러 줄·이미지·파일 전송 | 검증 범위 밖 |
| 전체 대화 DB 추출, BM25·의미 검색, 백그라운드 동기화 | 제공하지 않음 |
| 예약·반복·대량 발송 | 제공하지 않음 |

검증일은 2026-09-09입니다. 당시 입력 관련 호출에서 발생한 `window is not a usable app window` 오류의 내부 원인은 확인되지 않았습니다. 이 스킬의 복구 절차가 해당 런타임 오류 자체를 수정한 것은 아닙니다. 앱 업데이트·화면 구성·권한 차이에 따라 동작을 다시 확인해야 합니다.

## 데이터와 권한

- 카카오톡 로컬 DB, 암호화 키, 인증 캐시를 읽지 않습니다.
- 앱의 화면과 접근성 정보는 작업 중 Codex/Computer Use에 전달될 수 있습니다. 완전한 오프라인 처리를 보장하는 도구가 아닙니다.
- 대화 본문·수신자·스크린샷을 별도 파일이나 로그에 기본 저장하지 않습니다. 보고서나 Obsidian 기록도 일반 단건 전송마다 만들지 않습니다.
- 위 기본 동작이 Codex 서비스 전체의 대화 보관 정책을 없애는 것은 아닙니다. 필요한 방과 범위만 요청하세요.
- 대화방을 열면 읽음 상태가 바뀔 수 있으며, 읽음 상태 보존을 보장하지 않습니다.
- 전송 후 말풍선 확인을 상대방의 수신·읽음 확인으로 확대 해석하지 않습니다.
